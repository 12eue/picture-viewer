# 说明

## 功能

使用 Electron 创建的图片查看器，支持以下功能：

1. 支持通过单击图片左/右侧查看上/下一张图片
2. 右下角有个按钮可以点击可以切换图片实际大小、适应宽度、适应屏幕，默认是适应屏幕
3. 图片展示区占屏幕宽度要有 90%
4. 左侧侧边栏上方有切换栏，可以切换目录视图和当前目录图片视图
5. 目录视图可以展示当前打开的目录及其子目录，双击一个目录后，当前目录切换为选择的目录，当前目录视图的内容随之改变。
6. 当前目录图片视图可以有当前目录图片文件列表，支持快速滑动，点击图片后快速切换到指定图片，列表栏可以展示/收起，应该记住上次的打开状态
7. 菜单栏支持打开指定文件或打开目录。
8. 如果是通过双击图片打开软件，或者打开软件后选择打开指定图片，那么将该目录的目录作为当前目录。
9. 可以通过触控板的双指拉开/捏合来放大/缩小图片
10. 可以通过触控板的左右、鼠标滚轮上下、键盘的左右按键来切换上/下一张图片

## 运行

```bash
npm install
npm start
```

## 操作提示

- `Command/Ctrl + O`：打开图片
- `Command/Ctrl + Shift + O`：打开目录
- 图片展示区：鼠标滚轮或触控板滑动切换图片，每次连续滑动只切换一张
- 图片列表：触控板上下滑动仅滚动列表，不会改变图片展示区
- 键盘上下左右方向键：无论在哪个位置，均切换图片展示区内容
- 触控板捏合或 `Command/Ctrl + 滚轮`：缩放图片
- 右下角按钮：依次切换“适应屏幕”“适应宽度”“实际大小”
- 左下角侧边栏的收起按钮：显示/收起目录与图片列表，并记住上次状态
- 拖动侧边栏右侧边缘：调整侧边栏宽度；双击恢复默认宽度

## 构建 macOS 安装包

```bash
# 按当前 Mac 架构构建 DMG
npm run build:mac

# 指定 Intel Mac
npm run build:mac:x64

# 指定 Apple Silicon Mac
npm run build:mac:arm64
```

构建产物位于 `dist/`，例如：

```text
dist/图片查看器-1.0.2-x64.dmg
```

当前配置会跳过代码签名，适合本地安装和测试。正式分发时需要配置 Apple Developer 证书并完成公证。
